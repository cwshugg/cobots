**Workflows** are recommended ways to structure tasks to be completed for specific tasks.
Each workflow is defined in a separate file under [`workflows/`](./workflows).

All Cobots should be aware and adhere to the workflows, but these are *especially* important for the Director.
When creating tasks, assigning work, and laying out a project's tasks, these workflows should be used.
